# Worldfolio

A drivable portfolio for Aditya Raj Singh (`LENGND123`). The live site is https://adityarajsingh.co.in/. Arrow keys or WASD drive the car. Enter opens the project you are parked on. The first board is the stock prediction dashboard.

The orange world, follow camera, project boards, and profile chip follow the Worldfolio template. The driving-world idea is adapted from [Bruno Simon's folio-2019](https://github.com/brunosimon/folio-2019) (MIT). This is a separate implementation, with Aditya's GitHub projects in place of the original site.
