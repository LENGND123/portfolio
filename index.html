Notes from the desk

Keep the rubric on the server

DryRun lets Gemini score an answer, and the scoring rules stay in the API. The browser gets the feedback. It does not get the answer key.

A camera is an input device

Steering Wheel and GestureOS both start from MediaPipe hands. One maps two hands to an angle. The other maps a hand to the pointer and a keyboard.

Say what the simulator is

Ward 3 East replays a night of beds so the policies can be compared. The patients are synthetic. The page is a research exercise.
